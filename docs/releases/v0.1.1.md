# LocalSend GTK v0.1.1

A packaging and desktop-integration update for the unofficial Rust / GTK4 Linux client.

## Included in this release

- AppImage builds are now part of the GitHub release, with a matching
  `.AppImage.zsync` file and embedded `gh-releases-zsync` update information.
  Gearlever and AppImageUpdate can update in place after the release is
  published.
- New **Settings → File manager integrations** section for Dolphin, Nautilus
  and Nemo. Integrations are opt-in, can be installed or removed per file
  manager, and are never installed automatically by packages or at startup.
- Nautilus supports both a Python-free **Scripts** entry and a direct context
  menu through `nautilus-python`. Nemo uses a native `.nemo_action`.
- Bulk **Install all detected** and **Remove all** actions, dependency checks
  and clearer confirmation and result messages.
- AppImage desktop integration installs a user launcher and icon when requested.
  Its desktop file sets `StartupWMClass=org.localsend.localsend_gtk`, so the
  running window is associated with the launcher and dock actions work.
- All nine interface languages include the updated About text for this version.

## Downloads and requirements

Native **Linux x86_64** packages are provided as AppImage, DEB, RPM and tar.gz,
together with `SHA256SUMS`. They require **glibc 2.39+, GTK 4.12+ and
libadwaita 1.5+**.

The AppImage remains thin: it uses the host's GTK4/libadwaita runtime instead of
bundling a full desktop stack. The `.zsync` file adds update metadata, not GTK
libraries.

- AppImage: make it executable and run it, or integrate it from
  **Settings → Desktop integration**. Keep the `.AppImage.zsync` next to the
  AppImage if you manage updates manually.
- Debian/Ubuntu: `sudo apt install ./localsend-gtk_0.1.1-1_amd64.deb`
- Fedora: `sudo dnf install ./localsend-gtk-0.1.1-1.x86_64.rpm`
- Tar archive: extract it and run `sudo ./install.sh`, or
  `./install.sh "$HOME/.local"` for the current user.

Gearlever and AppImageUpdate only see an update after the GitHub release is
published; draft releases are ignored.

The repository includes AUR packaging recipes and a Flatpak manifest. This
release does not claim publication on AUR or Flathub, and the Flatpak sandbox
cannot install file manager integrations into the host's data directories.

## Validation

The release workflow checks that the tag, `Cargo.toml`, `Cargo.lock` and RPM spec
versions match, then builds and verifies the AppImage, its embedded update
information, the `.zsync` metadata and all checksums. Unit tests and Clippy run
before packaging.

This is an independent project, not an official LocalSend release. Feature
parity and physical-device compatibility testing are ongoing. Thanks to the
LocalSend and localsend-rs contributors.
